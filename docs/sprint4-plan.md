# План Спринта 4 — AI Gift Assistant

## 1. Приоритизация задач

### Must-have (обязательно сделать)

- Завершить ключевые эндпоинты Backend API:
  - регистрация, авторизация;
  - профиль пользователя (просмотр/редактирование);
  - история запросов;
  - (добавление/удаление);
  - напоминания.
- Полная интеграция Backend API ↔ AI Engine:
  - отправка пользовательского запроса,
  - получение рекомендаций,
  - формирование истории,
  - генерация ответа.
- Интеграция Backend ↔ ChromaDB:
  - сохранение эмбеддингов,
  - векторный поиск по истории.
- Завершить архитектуру уведомлений:
  - базовые события через Telegram/E-mail (в рамках сценариев напоминаний).
- Хранение данных пользователей, чатов, напоминаний и истории в PostgreSQL.
- Обновление документации:
  - OpenAPI/Swagger,
  - README по запуску и структуре проектов.

### Should-have (желательно сделать)

- Обработка ошибок при работе с избранным и напоминаниями.
- Улучшить отдачу ошибок API (структурированные ответы, коды).
- Улучшение тонкой настройки промптов для стабильных рекомендаций.

### Could-have (если останется время)

- Улучшение интерфейса:
  - история запросов (UI),
  - улучшение отображения рекомендаций,
  - интерфейс напоминаний.
- Интеграционные тесты полного цикла:
  - запрос → AI → Chroma → сохранение → отображение → уведомление.

---

## 2. Технический долг

- **Отзывы и оценки (UC8)** — не реализовано, переносится далее.
- **Производительность и масштабируемость** — нагрузочные тесты не проводились.
- **UI** — не покрывает полный сценарий end-to-end.
- **Мониторинг и алерты** — отсутствуют метрики, нет систем наблюдения.
- **Валидация данных** — требуется унификация схем API.
- **Telegram-уведомления** — работают частично, без полноценного планировщика.

---

## 3. Планирование улучшений

- Добавить структурированное логирование (user actions, AI calls, DB queries).
- Уточнить схемы запросов и ответов в OpenAPI.
- Покрыть базовые сценарии интеграционными тестами (регистрация, запрос, история).
- Добавить инструкции по запуску через Docker и `.env`.
- Оптимизировать работу с ChromaDB (кэширование, корректные коллекции).
- Улучшить обработку ошибок в AI Engine (таймауты, ограничение токенов).
