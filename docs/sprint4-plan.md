# Sprint 4 plan

## 1. Приоритизация задач для Спринта 4

- Определить ключевые задачи, необходимые для финальной подготовки проекта.
- Сфокусироваться на улучшении стабильности API, производительности и интерфейса.
- Расставить приоритеты:

**Высокий приоритет:**

- Оптимизация запросов к базе данных (PostgreSQL и Redis).
- Проверка корректной работы напоминаний и уведомлений.
- Тестирование интеграций с Telegram API.
- Исправление критических ошибок в backend и frontend.

**Средний приоритет:**

- Оптимизация интерфейса (Vue.js).
- Улучшение отображения подарков и списка событий.
- Добавление кэширования часто используемых запросов.

**Низкий приоритет:**

- Небольшие улучшения UX.
- Очистка и рефакторинг кода.

---

## 2. Определение технического долга

| Область      | Проблема                                   | Решение                                                   |
| ------------ | ------------------------------------------ | --------------------------------------------------------- |
| Backend      | Дублирование логики в контроллерах         | Вынести повторяющиеся функции в отдельные сервисы         |
| Frontend     | Частичное отсутствие типизации компонентов | Добавить строгую типизацию через TypeScript               |
| API          | Недостаточное логирование ошибок           | Добавить централизованный обработчик ошибок               |
| База данных  | Дублирование данных и слабые связи         | Оптимизировать структуру таблиц, добавить связи и индексы |
| Документация | Нет актуальных описаний интерфейсов        | Обновить архитектурные и API-документы                    |

---

## 3. Планирование улучшений

- Сократить время отклика API до 1 секунды.
- Внедрить кэширование запросов с помощью Redis.
- Улучшить адаптивность интерфейса.
- Обновить систему уведомлений (Email, Telegram).
- Добавить русскую локализацию.
- Подготовить проект к демонстрации: финальные тесты, Docker-конфигурация, документация.
