## 1. Введение

Цель документа — зафиксировать текущее состояние требований проекта **AI Gift Assistant** после реализации прототипа (ЛР-3), проверить соответствие утверждённым Use-cases (UC1–UC… по диаграмме), обнаружить отклонения и определить зоны, требующие доработки перед следующим спринтом.

## 3. Валидация Use-cases через прототип

### Проверено:

- UC1 — регистрация.
- UC2 — авторизация.
- UC3 — восстановление пароля (частично).
- UC4 — просмотр и редактирование профиля (частично).
- UC5 — работа с чатами (создание, удаление, просмотр).
- UC6 — генерация рекомендаций через OpenAI.
- UC7 — уточняющие параметры передаются на Backend.
- UC9 — создание и удаление напоминаний.
- Частичная интеграция Telegram/Email уведомлений.

### Не проверено:

- Полный end-to-end сценарий:
  - **запрос → AI → ChromaDB → ответ → история → уведомление**
- UC8 — оценка качества ответа.
- Полная работа поиска по чатам и напоминаниям.
- Структурированный поиск по векторным эмбеддингам Chroma.

---

## 4. Анализ отклонений от плана

1. **UI некоторых сценариев не завершён**  
   Не хватает окончательной интеграции форм, отображения состояния напоминаний, визуализации рекомендованных подарков.

2. **AI пайплайн завершён только частично**

   - OpenAI работает,
   - ChromaDB подключена,
   - но нет связки в единую цепочку.

3. **Напоминания работают неполностью**  
   Redis получает задачи, но триггеры для уведомлений не завершены.

4. **Уведомления (Telegram и Email)**  
   Реализованы частично, отправка работает, но не встроена в E2E.

5. **UC8 (Оценка результата)**  
   Не реализовано, перенесено в технический долг.

6. **Поиск по чатам и напоминаниям**  
   Базовый поиск есть, но сортировка и фильтры не реализованы.

7. **История запросов сохраняется частично**  
   Данные пишутся, но не используется поиск по эмбеддингам из Chroma.

---

## 5. Обновление документации требований

- Статусы всех Use-cases обновлены (реализовано/частично/не реализовано).
- UC8 перенесён в технический долг.
- Требования к напоминаниям (UC9) требуют уточнения логики Redis-триггеров.
- Требования к подсистеме рекомендаций должны включать интеграцию с ChromaDB.
- Необходимо расширить документ архитектуры, добавив:
  - обновлённую C4-диаграмму,
  - описание AI пайплайна,
  - интерфейсы модулей,
  - схемы взаимодействий.

---

## 6. Выводы

1. Прототип подтверждает значительную часть требований ЛР-2.
2. Ключевые функции реализованы: регистрация, авторизация, чаты, базовые рекомендации, напоминания (частично).
3. Интеллектуальный функционал (рекомендации подарков) работает, но требует завершения интеграции с ChromaDB и улучшения промптов.
4. Уведомления (Telegram/Email) работают как отдельные модули, но не как часть единого сценария.
5. UC8 остаётся нереализованным.
6. Для завершения MVP в Спринте 4 необходимо:
   - завершить AI пайплайн,
   - реализовать E2E работу с напоминаниями,
   - внедрить оценку ответа,
   - доработать поиск и историю.
